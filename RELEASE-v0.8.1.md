# Crank Reel v0.8.1

## English

The first planned GitHub release of Crank Reel, a hand-cranked pixel animation studio for Playdate.

- Draw and reorder up to 32 monochrome frames. Preview movement, generate in-between frames, and adjust how much crank travel each frame takes.
- Screen reels forward or backward with the crank. Choose one of four crank-driven tracks per reel.
- Export and import CR1 reel codes, including the soundtrack and frame holds. Older CR1 codes can be imported.
- Duplicate reels to experiment with alternate versions.

Download **CrankReel.pdx.zip** under **Assets** and upload it through [Playdate Sideload](https://play.date/account/sideload/). For Simulator use, extract the ZIP and open the PDX. The automatically generated source archive is for building the app.

## 日本語

Playdateのクランクで上映するドットアニメ工房「Crank Reel」の初回GitHub公開用リリースノートです。

- 最大32コマの白黒ドット絵を作成・並べ替えできます。中間コマを生成したり、各コマの送り幅を変えたりできます。
- クランクで正逆再生でき、作品ごとに4曲からBGMを設定できます。
- BGMやコマの「間」を含むCR1コードを書き出し・取り込みできます。以前のCR1コードも読み込めます。
- リールを丸ごと複製して別バージョンを作れます。

**Assets** の **CrankReel.pdx.zip** をダウンロードし、[Playdate Sideload](https://play.date/account/sideload/)でアップロードしてください。SimulatorではZIPを解凍してPDXを開きます。GitHubが自動生成するソースアーカイブはビルド用です。
